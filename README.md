# DMT412 AR Cards

An AR greeting card and an AR business card for Android, made in Unity 6000.5.6f1 with Vuforia.

## Opening the project

Two things are left out of this repository on purpose. Add them before you open the scene.

1. **Asset Store packs.** They are licensed to me and can't be shared publicly. Import them from the Unity Asset Store so they land in these folders:
   - `Assets/polyperfect` (Poly Christmas)
   - `Assets/ithappy` (Christmas Pack FREE)
   - `Assets/Christmas Tree - POLYCRAFT Series`
   - `Assets/PolyPeople_SantaClaus`
2. **A Vuforia licence key.**
   1. Create a free Basic licence at developer.vuforia.com.
   2. Paste it in Unity under **Window > Vuforia Configuration**. Unity saves it to `Assets/Resources/VuforiaConfiguration.asset`.
   3. Leave that file uncommitted. It is git-ignored.
